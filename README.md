# MortarCalculator

## 소개

MortarCalculator는 Arma Reforger 공식 M252 박격포와 M821 HE 탄약을 위한 가벼운 콘솔 박격포 계산기입니다. 외부 패키지 없이 Python 표준 라이브러리만 사용하며, 탄도표는 `ballistics.json`에서 실행 시 불러옵니다.

계산기는 박격포 격자, 목표 격자, 고도, 풍향, 풍속을 입력받아 추천 장약, 사각, 비행시간, 분산, 풍향 보정, 보정 방향각, 보정 사각을 표시합니다.

## 사용 방법

Windows에서는 `run.bat`을 더블 클릭하면 바로 실행됩니다.

```bat
run.bat
```

또는 터미널에서 직접 실행할 수 있습니다.

```bash
python calculator.py
```

필요한 외부 설치 명령은 없습니다. `pip install`이나 가상 환경은 필요하지 않습니다.

## 입력 형식

프로그램은 다음 값을 순서대로 입력받습니다.

1. 박격포 격자
2. 목표 격자
3. 박격포 고도
4. 목표 고도
5. 풍향
6. 풍속

격자는 10자리 숫자 또는 `동,북` 형식을 지원합니다.

예시:

```text
박격포 격자
> 1234512345
목표 격자
> 1273812862
박격포 고도
> 118
목표 고도
> 145
풍향
> 270
풍속
> 6
```

초기 계산 후 사격 수정을 입력하면 목표 좌표를 자동 보정하고 사격 제원을 다시 계산합니다.

지원 형식:

```text
LEFT 20
RIGHT 10
ADD 50
DROP 30
```

빈 줄을 입력하면 종료합니다.

## 풍향 계산

풍향은 바람이 불어오는 방향을 도 단위로 입력합니다. 계산기는 박격포에서 목표까지의 방향각을 기준으로 바람 벡터를 분해합니다.

- 횡풍은 풍편을 만들며 방향각 보정으로 변환됩니다.
- 역풍은 탄착을 짧게 만드는 성분으로 계산됩니다.
- 순풍은 탄착을 길게 만드는 성분으로 계산됩니다.
- 비행시간이 길수록 바람 반응이 커지도록 계산합니다.

풍향 보정은 탄체 비행시간, 사거리, 횡풍, 역풍, 순풍을 함께 사용합니다. 단순한 장약별 고정 계수만으로 보정하지 않습니다.

## 탄도 계산

탄도표는 `ballistics.json`에 저장되어 있으며 Python 코드에 하드코딩되어 있지 않습니다. 각 장약은 사거리별 사각, 비행시간, 분산 값을 가집니다.

계산기는 요청 사거리가 포함되는 장약을 찾고 직접 구현한 선형 보간 함수로 다음 값을 계산합니다.

- 사각
- 비행시간
- 분산

고도차는 박격포 고도와 목표 고도의 차이를 사용해 밀 단위 사각 보정으로 반영됩니다.

## 향후 계획

- 실제 게임 업데이트에 맞춘 M821 탄도표 검증.
- 더 다양한 격자 입력 형식 지원.
- 장약 선택 모드 추가.
- 사격 수정 기록 표시.
- 간단한 자동 테스트 추가.
