# MortarCalculator

공식 **M252 박격포**와 **M821 HE** 탄약, **0-4번 장약**을 위한 Arma Reforger 전문 박격포 사격 통제 계산기입니다.

## 주요 기능

- JSON 탄도표를 기반으로 한 M252/M821 장약 추천.
- `scipy.interpolate.interp1d`를 사용한 사거리, 사각, 비행시간, 보정값, 분산의 선형 보간.
- 관측자의 방향각과 거리 관측값을 이용한 목표 좌표 계산.
- 박격포보다 높거나 낮은 목표에 대한 고도차 보정.
- 풍향, 풍속, 사격 방향각, 사거리, 탄체 비행시간을 사용하는 바람 성분 계산.
- 자동 방향각 보정 및 사각 보정.
- `config.json`에 박격포, 관측자, 바람, 설정 기본값을 자동 저장.
- 야전 사격 임무에 맞춘 터미널 UI.

## 사용 방법

저장소 루트에서 계산기를 실행합니다.

```bash
python calculator.py
```

프로그램은 다음 정보를 입력받습니다.

1. 박격포 위치: 동향 좌표, 북향 좌표, 고도.
2. 관측자 위치: 동향 좌표, 북향 좌표, 고도.
3. 풍속: 초속 미터.
4. 풍향: 바람이 **불어오는 방향**을 도 단위로 입력.
5. 관측자 기준 목표 방향각과 목표 거리.
6. 목표 고도.

빈 입력은 표시된 기본값을 사용합니다. 각 사격 임무 후 최신 박격포, 관측자, 바람 입력값이 `config.json`에 저장됩니다.

## 풍향/풍속 계산

바람은 박격포-목표 방향각을 기준으로 분해됩니다.

- 횡풍은 측방 풍편을 추정하고 이를 밀 단위 방향각 보정으로 변환합니다.
- 역풍/순풍은 거리 보정을 추정합니다.
- 탄체 비행시간이 계산에 포함되므로, 더 느린 고각 사격은 더 빠른 사격보다 바람 영향을 크게 받습니다.

UI에서는 장약별 단순 고정 계수를 사용하지 않습니다. 보정값은 바람 벡터 기하, 사거리, 보간된 비행시간을 통해 생성됩니다.

## 탄도 계산

탄도 데이터는 `data/m821.json`에 있습니다. 각 장약표에는 다음 값이 저장됩니다.

- `range`
- `mil`
- `time`
- `elevation_correction`
- `dispersion`

`ballistics.py`는 이 표를 불러와 `scipy.interpolate.interp1d` 보간기를 생성합니다. 계산기는 요청된 박격포-목표 사거리를 포함하는 모든 장약을 추천하고 유효한 모든 사격 제원을 표시합니다.
